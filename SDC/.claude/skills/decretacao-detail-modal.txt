================================================================================
                    MODAL DE DETALHES DE DECRETACOES
================================================================================

Data: 2026-03-13
Projeto: NewSDC
Tecnologias: Vue 3 + Composition API + Tailwind CSS + Atomic Design

--------------------------------------------------------------------------------
DESCRICAO
--------------------------------------------------------------------------------

Modal moderno para visualizacao de detalhes de processos de decretacao
(reconhecimentos de desastre). Implementado com 4 abas seguindo o padrao
do sistema legado, mas com design system atualizado.

ABAS:
  1. Informacoes Basicas - Dados gerais do processo
  2. Dados do Decreto - Vigencia e reconhecimento oficial
  3. Totais de Desastres - Danos humanos, materiais e prejuizos
  4. Pedido AH - Pedidos de ajuda humanitaria

--------------------------------------------------------------------------------
ARQUIVOS CRIADOS
--------------------------------------------------------------------------------

1. SDC/resources/js/Components/Organisms/Decretacoes/Details/DecretacaoDetailModal.vue
   - Modal principal usando Modal.vue como base
   - Header com gradiente e info do tipo de desastre
   - Navegacao de abas com icones
   - Suporte a light/dark mode
   - Props: show, processo, loading
   - Emits: close

2. SDC/resources/js/Components/Organisms/Decretacoes/Details/tabs/TabInformacoes.vue
   - Data de entrada, tipo de processo
   - Lista de municipios afetados
   - Status do processo
   - Analista responsavel
   - Processo SEI

3. SDC/resources/js/Components/Organisms/Decretacoes/Details/tabs/TabDadosDecreto.vue
   - Contador visual de dias restantes
   - Barra de progresso da vigencia
   - Dados do decreto municipal/estadual
   - Reconhecimento oficial (portaria federal, DOU, DOMG)

4. SDC/resources/js/Components/Organisms/Decretacoes/Details/tabs/TabTotaisDesastres.vue
   - Toggle: Total Geral / Por Municipio
   - Card de danos humanos (quantidade)
   - Card de danos materiais (quantidade + valor R$)
   - Card de prejuizos economicos publicos
   - Card de prejuizos economicos privados

5. SDC/resources/js/Components/Organisms/Decretacoes/Details/tabs/TabPedidoAH.vue
   - Lista de pedidos de ajuda humanitaria
   - Status badge por pedido
   - Empty state quando nao ha pedidos

--------------------------------------------------------------------------------
ARQUIVOS MODIFICADOS
--------------------------------------------------------------------------------

1. SDC/resources/js/Components/Organisms/Decretacoes/ProcessoGrid.vue
   - Import do DecretacaoDetailModal
   - Estado: showDetailModal, selectedProcesso

2. SDC/resources/js/Components/Organisms/Decretacoes/ProcessoTable.vue
