TAREFA 2: IMPLEMENTACAO DE IMPRESSAO NO MODULO DECRETACOES
--------------------------------------------------------------------------------

CONTEXTO:
- O modulo PAE ja tinha o padrao de impressao funcionando
- O modulo Decretacoes tinha o PrintDecretacaoModal.vue mas nao estava integrado
- ProcessoTable e ProcessoCard ja emitiam evento @print

SOLUCAO APLICADA:

1. ProcessoGrid.vue:
   - Adicionado handler @print no ProcessoCard
   - Adicionado defineEmits(['print']) para propagar o evento

2. ProcessoIndexTemplate.vue:
   - Importado PrintDecretacaoModal
   - Importado computed de vue
   - Adicionado estados: printModalOpen, selectedProcessoId
   - Adicionado computed: selectedProcesso
   - Adicionado handlers: handlePrint(), closePrintModal()
   - Conectado evento @print no ProcessoGrid e ProcessoTable
   - Adicionado componente PrintDecretacaoModal no template

ARQUIVOS MODIFICADOS:
- resources/js/Components/Organisms/Decretacoes/ProcessoGrid.vue
- resources/js/Templates/Decretacoes/ProcessoIndexTemplate.vue

FLUXO DE IMPRESSAO IMPLEMENTADO:
1. Usuario clica no icone de impressora (TableActions)
2. ProcessoCard/ProcessoTable emite evento @print com ID
3. ProcessoGrid propaga evento para ProcessoIndexTemplate
4. handlePrint(id) atualiza estados
5. PrintDecretacaoModal abre com dados do processo
6. Usuario pode imprimir via browser print dialog

PADRAO SEGUIDO:
- Mesmo padrao do modulo PAE (PrintPaeProtocoloModal)
- Componentes reutilizaveis: BasePrintModal, PrintHeader, PrintSection, PrintRecibo
