## 5. Playwright Snapshots (a executar)

Suite a criar em Fase 1.4:

```bash
# tests/visual/responsive-baseline.spec.js
test.describe.parallel('Baseline visual', () => {
  const pages = ['/dashboard', '/pae', '/decretacoes', '/orgaos', '/admin/permissions/users'];
  const viewports = [
    { name: 'mobile-s', width: 320 },
    { name: 'mobile-m', width: 375 },
    { name: 'tablet-p', width: 768 },
    { name: 'tablet-l', width: 1024 },
    { name: 'desktop', width: 1440 },
  ];

  for (const url of pages) {
    for (const vp of viewports) {
      test(`${url} @ ${vp.name}`, async ({ page }) => {
        await page.setViewportSize({ width: vp.width, height: 900 });
        await page.goto(url);
        await expect(page).toHaveScreenshot(`${url.replace(/\//g, '-')}-${vp.name}.png`);
      });
    }
  }
});
```

**Status:** **A EXECUTAR** - depende de app rodando + autenticacao no Playwright.
